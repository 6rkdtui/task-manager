# Task Manager

Данный проект представляет собой консольное приложение для управления задачами.

Учебный проект создан для закрепления знаний Python, ООП, работы с базами данных, архитектуры приложений и автоматического тестирования.

## Функционал

- создание задачи;
- получение задачи по ID;
- просмотр всех задач;
- изменение задачи;
- отметка задачи выполненной;
- удаление задачи;
- консольное меню;
- обработка некорректного числового ввода;
- хранение задач в PostgreSQL.

## Используемые технологии

- Python
- ООП
- dataclasses
- type hints
- PostgreSQL
- psycopg
- python-dotenv
- pytest
- unittest.mock

## Архитектура

Проект разделён на несколько слоёв:

```text
main.py
↓
TaskService
↓
TaskRepository
↓
PostgreSQL
```

- `main.py` — консольный интерфейс;
- `TaskService` — бизнес-логика приложения;
- `TaskRepository` — работа с базой данных;
- `Task` — модель задачи;
- `database.py` — конфигурация подключения к PostgreSQL.

Такое разделение позволяет отделить пользовательский интерфейс и бизнес-логику от конкретной реализации хранения данных.

## PostgreSQL

Начиная с версии 0.7, проект использует PostgreSQL вместо SQLite.
Подключение выполняется через драйвер psycopg.
Параметры подключения хранятся в .env:

```env
DB_HOST=127.0.0.1
DB_PORT=5432
DB_NAME=task_manager
DB_USER=task_user
DB_PASSWORD=your_password
```

Файл .env не должен попадать в Git.

Таблица tasks содержит:

```text
id
title
description
is_completed
```

Для операций записи используются транзакции:

- commit() после успешной операции;
- rollback() при возникновении ошибки;
- курсоры закрываются после выполнения операций.

## Тестирование

Для автоматического тестирования проекта используется `pytest`.

Тестами покрыты:

- создание задачи;
- получение задачи;
- получение списка задач;
- обновление задачи;
- частичное обновление задачи;
- завершение задачи;
- удаление задачи;
- работа с несуществующими задачами;
- получение пустого списка;
- бизнес-логика `TaskService`;
- взаимодействие `TaskService` с Repository через mock-объекты.

### Тестирование TaskRepository

Тесты `TaskRepository` работают с отдельной PostgreSQL-базой:

```text
task_manager_test
```

Настройки тестовой базы хранятся в:

```text
.env.test
```

Перед каждым тестом таблица `tasks` очищается, поэтому тесты не зависят друг от друга и не изменяют данные основной базы приложения.

### Тестирование TaskService

`TaskService` тестируется отдельно от реальной базы данных с использованием:

```python
Mock(spec=TaskRepository)
```

Это позволяет проверять бизнес-логику независимо от PostgreSQL.

Запуск всех тестов:

```bash
python -m pytest -v
```

## Установка и запуск

Создать виртуальное окружение:

```bash
python -m venv .venv
```

Установить зависимости:

```bash
python -m pip install -r requirements.txt
```

Создать PostgreSQL-базу и настроить .env.

Создать таблицу:

```bash
python create_tables.py
```

Запустить приложение:

```bash
python main.py
```
