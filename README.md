# Task Manager

Данный проект представляет собой программу по управлению задачами. Учебный проект для закрепления знаний Python и ООП на практике.

## Функционал:

- создание задачи;
- получение задачи по ID;
- просмотр всех задач;
- изменение задачи;
- отметка задачи выполненной;
- удаление задачи;
- консольное меню;
- обработка некорректного числового ввода.

## Используемые технологии

Python, ООП, dataclasses, type hints.
