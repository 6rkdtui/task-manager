# Task Manager

Данный проект представляет собой программу по управлению задачами. Учебный проект для закрепления знаний Python и ООП на практике. На данный момент он умеет создавать задачи, выводить задачи, удалять и обновлять задачи.

Функционал:

- создание задачи;
- получение задачи по ID;
- просмотр всех задач;
- изменение задачи;
- отметка задачи выполненной;
- удаление задачи.

Используемые технологии: Python, ООП, dataclasses, type hints.

Структура проекта:
Task_manager/
├── main.py
├── README.md
└── .gitignore

Инструкция по запуску:
python main.py
