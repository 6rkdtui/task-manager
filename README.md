# Task Manager

Данный проект представляет собой программу по управлению задачами. Учебный проект для закрепления знаний Python, ООП и архитектуры приложений на практике.

## Функционал

- создание задачи;
- получение задачи по ID;
- просмотр всех задач;
- изменение задачи;
- отметка задачи выполненной;
- удаление задачи;
- консольное меню;
- обработка некорректного числового ввода;
- хранение задач в базе данных SQLite.

## Используемые технологии

Python, ООП, dataclasses, type hints, SQLite, pytest.

## Архитектура

Проект разделён на несколько слоёв:

```text
main.py
↓
TaskService
↓
TaskRepository
↓
SQLite
```

- `main.py` — консольный интерфейс;
- `TaskService` — бизнес-логика приложения;
- `TaskRepository` — работа с базой данных;
- `Task` — модель задачи.

## Работа с базой данных

В версии 0.5 улучшена работа с SQLite:

- курсоры закрываются через `try/finally`;

- при ошибках операций записи выполняется `rollback()`;

- ошибки SQLite после отката пробрасываются выше;

- изменения объектов `Task` выполняются только после успешного `commit()`;

- соединение с базой данных закрывается через `TaskService`.


## Тестирование

Для автоматического тестирования проекта используется `pytest`.

Тестами покрыты:
- CRUD-операции `TaskRepository`;
- получение пустого списка задач;
- обработка несуществующих задач;
- полное и частичное обновление задач;
- бизнес-логика `TaskService`;
- взаимодействие `TaskService` с `TaskRepository` с использованием mock-объектов.

Для тестов `TaskRepository` используется временная SQLite-база данных, создаваемая через fixture `tmp_path`. Это позволяет запускать тесты независимо от основной базы данных приложения.

Для тестирования `TaskService` используется `Mock(spec=TaskRepository)`, благодаря чему сервисный слой тестируется отдельно от SQLite.

Запуск тестов:

```bash
python -m pytest
```
